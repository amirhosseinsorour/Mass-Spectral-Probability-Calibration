# Full inputs stay local

The full dataset is not included or redistributed here.

For full-data execution, independently obtain the original IdentityMF min–max table and place it in this directory as `IdentityMF_MinMax_fullResults.txt`. It must contain 2,073,600 headerless, tab-separated rows with the seven columns documented in [data/README.md](../README.md).

The `.gitignore` rules exclude full inputs and generated row-level data. The public example remains under [`../sample/`](../sample/README.md). See [reproducibility](../../docs/reproducibility.md) for execution instructions and verification limits.
