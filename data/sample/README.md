# IdentityMF min–max example

[`identitymf_minmax_sample.tsv`](identitymf_minmax_sample.tsv) contains **20,736 rows**, including 144 same-compound rows. It is a byte-for-byte copy of the supplied archive member `IdentityMF/IdentityMF_MinMax_fullResults.txt`, renamed to avoid implying that it contains the full experiment.

This is a precomputed comparison-input example, not raw spectra and not the processed training dataset. The main notebooks use it by default. Its results cannot be used to reproduce the final report's numerical results.

The [data documentation](../README.md) provides the seven-column schema, counts, source attribution and full-data requirements. Exact hashes are recorded in [source provenance](../../docs/source_provenance.json). NIST's [data notice and terms](../../THIRD_PARTY_NOTICES.md) apply.
