# Notebook order

The public notebooks are adapted from the author's four supplied research notebooks. Outputs and execution counters are cleared; published full-study figures and aggregate metrics are retained separately under [`assets/`](../assets/README.md) and [`results/`](../results/README.md).

| Order | Notebook | Main responsibility | Local outputs |
| ---: | --- | --- | --- |
| 1 | [`01_preprocess.ipynb`](01_preprocess.ipynb) | Validate input, reconstruct scores, create pair IDs and grouped split | Base, train and test CSVs |
| 2 | [`02_eda.ipynb`](02_eda.ipynb) | Check completeness, class balance, pair multiplicity and score distributions | Interactive tables and plots |
| 3 | [`03_calibration.ipynb`](03_calibration.ipynb) | Fit the three mappings and generate test predictions | Three prediction CSVs |
| 4 | [`04_evaluation.ipynb`](04_evaluation.ipynb) | Align prediction files and compare probability, ranking and classification metrics | Evaluation tables and six PNG plots |

Start Jupyter in the repository root or its `notebooks/` folder and choose your project environment's Python kernel. `project_config.py` resolves paths consistently from either location. Sample mode is the default. The [reproducibility guide](../docs/reproducibility.md) explains full mode and the alternative headless runner.

Run all cells in each notebook in order. The three downstream notebooks require the files generated by their predecessors in the **same data mode**. Full and sample outputs use separate directories.

The score formulas, seed, pair split, model fitting code and metric definitions are retained. Publication changes cover paths, input and alignment checks, source-rounding tolerance, a plotting feature-name warning and notebook metadata cleanup. See the [change notes](../docs/reproducibility.md#changes-from-the-supplied-notebooks).
